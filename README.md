# GitHub Pages Site

This `docs/` folder contains a static site for GitHub Pages.

## Publish steps

1. Push this repository to GitHub.
2. Open repository **Settings** → **Pages**.
3. Under **Build and deployment**:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main`
   - **Folder**: `/docs`
4. Save, then wait for deployment.

Your site URL will be shown in the Pages settings once built.
